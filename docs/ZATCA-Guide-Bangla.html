১. প্যাকেজটা কী করে

সৌদি আরবে প্রতিটা invoice ZATCA-র নিয়ম মেনে বানাতে হয়: নির্দিষ্ট XML format, digital signature, QR code, আর ZATCA-র server-এ পাঠানো। এই প্যাকেজ সেই কাজগুলো আপনার Laravel app-এর ভেতর থেকে করে দেয়।

কাজপ্যাকেজ কী করে
Onboardingআপনার device (POS / branch / software)-কে ZATCA-তে নিবন্ধন করে certificate (CSID) নিয়ে আসে।
Invoice বানানোUBL 2.1 XML বানায়, হিসাব (মোট, VAT) করে।
Signature আর QRXML-এ digital signature দেয়, আর receipt-এ ছাপার জন্য QR code বানায়।
ZATCA-তে পাঠানোB2C invoice report করে, B2B invoice clear করে।
RetryInternet বা ZATCA বন্ধ থাকলে invoice pending রাখে, পরে আবার পাঠায়।
Certificate নবায়নমেয়াদ শেষের আগে certificate renew করে, invoice chain না ভেঙে।

দুই ধরনের invoice

ধরনকার জন্যZATCA-তে কী হয়
SimplifiedB2C (সাধারণ ক্রেতা)Report — ক্রেতাকে আগে দিয়ে দিন, ২৪ ঘণ্টার মধ্যে ZATCA-কে জানান। ফল: REPORTED
StandardB2B (ব্যবসা)Clear — আগে ZATCA অনুমোদন দেবে, তারপর ক্রেতাকে দেবেন। ফল: CLEARED

৪. ফলREPORTED / CLEARED, অথবা error
Invoice chain কী? প্রতিটা device-এর invoice-গুলো একটা শিকলের মতো জোড়া: প্রত্যেকটার একটা ক্রমিক নম্বর (ICV: 1, 2, 3…) থাকে, আর আগের invoice-এর hash (PIH) থাকে। প্যাকেজ এটা নিজে সামলায়। দুটো invoice একসাথে বানালেও database lock-এর কারণে নম্বর কখনো একই হয় না।
মনে রাখুন: ZATCA একবার গ্রহণ করা (REPORTED / CLEARED) invoice আর বদলানো বা আবার পাঠানো যায় না। ভুল হলে credit note বা debit note দিতে হবে।

৪. প্রতিটা ফাইল কী কাজ করে

মূল অংশ

ফাইলকাজ
src/ZatcaManager.phpপ্যাকেজের মস্তিষ্ক। onboard(), renew(), issue(), submit(), issueAndSubmit() — সব এখানে। Invoice-এর ICV/PIH chain, database lock আর retry-ও এখানে সামলানো হয়।
src/Facades/Zatca.phpZatca::onboard(...), Zatca::issue(...) লেখার shortcut। ভেতরে ZatcaManager-কেই ডাকে।
src/ZatcaServiceProvider.phpLaravel-এ প্যাকেজ চালু করে: config যোগ, migration load, artisan command register। Composer নিজে থেকেই এটা চিনে নেয়।
config/zatca.phpতিনটা environment-এর URL (sandbox, simulation, production), sandbox OTP, timezone (Asia/Riyadh), HTTP timeout।
src/Exceptions/ZatcaException.phpপ্যাকেজের সব error এই ধরনের exception হিসেবে আসে। try / catch (ZatcaException $e) দিয়ে ধরুন।

Data — invoice-এর তথ্য

ফাইলকাজ
src/Data/InvoiceData.phpএকটা invoice / credit note / debit note-এর সব তথ্য: নম্বর, ধরন, লাইন, ক্রেতা, তারিখ। মোট টাকা আর VAT হিসাব করে। ভুল তথ্য দিলে সাথে সাথে error দেয় (যেমন B2B-তে ক্রেতার ঠিকানা না দিলে)।
src/Data/InvoiceLine.phpInvoice-এর এক লাইন: পণ্যের নাম, পরিমাণ, দাম, VAT category (S / Z / E / O) আর হার।
src/Data/Buyer.phpক্রেতা: নাম, VAT নম্বর বা অন্য ID, ঠিকানা।
src/Data/Address.phpসৌদি জাতীয় ঠিকানা: রাস্তা, building নম্বর (৪ ডিজিট), এলাকা, শহর, postal code (৫ ডিজিট)।

Models — database

ফাইলকাজ
src/Models/ZatcaDevice.phpএকটা device (EGS unit)। বিক্রেতার তথ্য, private key, certificate, আর invoice chain রাখে। Private key আর secret APP_KEY দিয়ে encrypt করা থাকে। isReady(), certificateExpired() ইত্যাদি method আছে।
src/Models/ZatcaDocument.phpসাইন করা প্রতিটা invoice আর ZATCA-র উত্তর। status, qr_code, finalXml(), errors(), warnings()।
src/Concerns/HasZatcaDocuments.phpআপনার নিজের Order বা Invoice model-এ এই trait দিলে $order->zatcaDocument দিয়ে ZATCA document পাবেন।

Support — ভেতরের যন্ত্রপাতি

এগুলো সরাসরি ব্যবহার করতে হয় না, তবে কোনটা কী করে জানা থাকলে সমস্যা খুঁজতে সুবিধা হয়।

ফাইলকাজ
src/Support/CsrGenerator.phpOnboarding-এর জন্য secp256k1 private key আর CSR বানায়। CSR-এ বিক্রেতার নাম, VAT নম্বর, EGS serial, branch ইত্যাদি যায়।
src/Support/Certificate.phpZATCA-র দেওয়া certificate পড়ে: মেয়াদ, issuer, serial নম্বর, public key, signature।
src/Support/InvoiceXmlBuilder.phpZATCA-র format-এ UBL 2.1 XML বানায় — বিক্রেতা, ক্রেতা, লাইন, VAT, মোট টাকা।
src/Support/InvoiceSigner.phpXML-এর hash বের করে, private key দিয়ে digital signature (XAdES) দেয়, আর QR code বসায়।
src/Support/QrCode.phpQR-এর ডেটা TLV format-এ বানায় (বিক্রেতা, VAT নম্বর, সময়, মোট, VAT, hash, signature…)। কোনো মান ২৫৫ byte-এর বেশি হলে error দেয়।
src/Support/ZatcaApi.phpZATCA server-এর সাথে কথা বলে: compliance, production CSID, renew, report, clear। ZATCA-র উত্তর থেকে status, error, warning বের করে। Server error (5xx) বা rate limit (429) চিনে নেয়।

Console — artisan command

ফাইলকাজ
src/Console/OnboardCommand.phpzatca:onboard — device onboard বা renew।
src/Console/SubmitPendingCommand.phpzatca:submit-pending — যেসব invoice এখনো ZATCA-তে যায়নি, সেগুলো পাঠায়।
src/Console/StatusCommand.phpzatca:status — সব device-এর অবস্থা, certificate-এর মেয়াদ, pending সংখ্যা।
src/Console/PayloadCommand.phpzatca:payload — Postman-এর জন্য invoice-এর body বা device-এর credentials দেখায়।

use Illuminate\Support\Str;

$device = ZatcaDevice::create([
    'environment'     => 'sandbox',
    'seller_name'     => 'Al Noor Trading Co',
    'vat_number'      => '399999999900003',
    'crn'             => '1010010000',
    'street'          => 'Prince Sultan',
    'building_number' => '2322',
    'district'        => 'Al-Murabba',
    'city'            => 'Riyadh',
    'postal_code'     => '23333',
    'egs_name'        => 'POS-01',
    'egs_serial'      => '1-MyInventory|2-1.0|3-'.Str::uuid(),
    'branch_name'     => 'Riyadh Branch',
    'industry'        => 'Supply activities',
    'invoice_types'   => '1100',
]);

Zatca::onboard($device);              // sandbox: OTP নিজে থেকে
Zatca::onboard($device, '482913');    // simulation / production: Fatoora portal-এর OTP

B2C (Simplified) invoice — report

use delwarhossaindev\Zatca\Data\{InvoiceData, InvoiceLine, Buyer, Address};

$document = Zatca::issueAndSubmit($device, new InvoiceData(
    number: 'INV-1001',
    type: InvoiceData::SIMPLIFIED,
    lines: [
        new InvoiceLine('Rice 5kg', quantity: 2, unitPrice: 45.50),
        new InvoiceLine('Medicine', 1, 30, InvoiceLine::ZERO_RATED, 0,
            'VATEX-SA-35', 'Medicines and medical equipment'),
    ],
), $order);                  // $order = আপনার নিজের model (ঐচ্ছিক)

$document->status;           // REPORTED
$document->qr_code;          // receipt-এ ছাপুন

B2B (Standard) invoice — clear

$document = Zatca::issueAndSubmit($device, new InvoiceData(
    number: 'INV-1002',
    type: InvoiceData::STANDARD,
    lines: [new InvoiceLine('Laptop', 1, 2500)],
    buyer: new Buyer(
        name: 'ACME Trading LLC',
        vatNumber: '399999999800003',      // অথবা identification + identificationScheme
        address: new Address('Salah Al-Din', '1111', 'Al-Murooj', 'Riyadh', '12222'),
    ),
    paymentMeans: '30',                    // 10 নগদ, 30 বাকি, 42 ব্যাংক, 48 কার্ড
));

$document->status;       // CLEARED
$document->finalXml();   // ZATCA-র stamp দেওয়া XML — এটাই ক্রেতাকে দিন

৯. Status-এর মানে আর কী করবেন

Statusমানেকী করবেন
pendingসাইন হয়েছে, ZATCA এখনো পায়নি (বা ZATCA সাময়িক বন্ধ ছিল)কিছু না — zatca:submit-pending নিজে পাঠাবে
REPORTEDB2C invoice ZATCA গ্রহণ করেছেশেষ। Warning থাকলে পরের invoice-এ ঠিক করুন
CLEAREDB2B invoice ZATCA অনুমোদন দিয়েছেfinalXml() ক্রেতাকে দিন
NOT_REPORTED / NOT_CLEAREDZATCA বাতিল করেছেerrors() দেখে তথ্য ঠিক করে নতুন invoice দিন
ERRORঅন্য কোনো সমস্যা (যেমন credential ভুল)errors() আর response দেখুন

১০. সাধারণ error আর সমাধান

Error messageকেন হয় / সমাধান
Complete ZATCA onboarding of this device before issuing invoices.Device এখনো onboard হয়নি। আগে zatca:onboard চালান।
This device is not onboarded for simplified invoices.Device-এর invoice_types এই ধরন দেয় না। 1100 দিয়ে নতুন device বানিয়ে onboard করুন।
An OTP from the Fatoora portal is required outside the sandbox.Simulation / production-এ --otp= দিন। OTP পাবেন fatoora.zatca.gov.sa থেকে (অল্প সময় valid থাকে)।
Standard invoices need the buyer name and address.B2B invoice-এ Buyer-এর সাথে Address দিন।
Standard invoices need the buyer VAT number or another buyer identification.ক্রেতার vatNumber, অথবা identification + identificationScheme (যেমন CRN) দিন।
Only SAR invoices are supportedএখন শুধু সৌদি রিয়াল চলে। currency বাদ দিন বা SAR দিন।
Credit and debit notes need the original invoice number and a reason.originalInvoiceNumber আর noteReason দিন।
VAT category Z needs 0% VAT and an exemption reason code and text.Z / E / O লাইনে হার 0 আর কারণ (যেমন VATEX-SA-35) দিন।
Document ... was already REPORTED.গ্রহণ করা invoice আবার পাঠানো যায় না। বদলাতে চাইলে credit / debit note দিন।
ZATCA is temporarily unavailable (HTTP 503) ... stays pendingZATCA-র server সমস্যা। কিছু করতে হবে না, scheduler পরে পাঠাবে।
Could not reach ZATCA: ...Internet নেই বা firewall আটকাচ্ছে। Document pending থাকে, পরে যাবে।
This device has already issued invoices. Use renew()Certificate এখনো valid। নতুন onboarding না, zatca:onboard 1 --renew চালান।
Unable to generate private keyServer-এর OpenSSL-এ secp256k1 নেই। দেখুন: openssl ecparam -list_curves | grep secp256k1
QR tag 1 is ... bytes long; ZATCA allows at most 255.বিক্রেতার নাম খুব লম্বা (আরবিতে ~১২৭ অক্ষরের বেশি)। নাম ছোট করুন।
Certificate-এর মেয়াদ শেষ হয়ে গেলে? তখন renew কাজ করে না। আবার zatca:onboard 1 --otp=... চালান — invoice chain (ICV / PIH) আগের জায়গা থেকেই চলবে।
